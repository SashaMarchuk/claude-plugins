# harness-rebuild — from-scratch rebuild spike for the harness/orchestrator plugin

Status (2026-10-29): **frozen.** The first beta ships on harness v0.6.0 plus safety hardening; this
spike resumes after the beta.

- `context.md`, `prompt.md`, `questions.md` — the round-1 interview-handoff package (2026-09-13).
- `round-1/ANALYSIS-01.md` + `ANALYSIS-01-ERRATA.md` — round 1 collected (interview 2026-09-13 → 09-19).
- `research/` — platform probes, landscape, adoption verdicts, architecture options, specs, judges, red
  teams, `architecture/BUILD-PLAN.md`, eval plan.
- `round-2/` — round-2 package (2026-09-21). **Not run yet.**

Requirement text of record lives in `openspec/specs/harness/`; nothing here is a requirement until it is
promoted through an OpenSpec change after round 2 (see `.planning/todos/pending/20261103-harness-rebuild-requirements-after-round-2.md`).

Published with redactions. Raw interview transcripts are not stored (only extracted requirements), so
row anchors like `[118]` and references to `round-1/TRANSCRIPT-01.md` or `research/extract/{by-item,
corrections,meta}.md` point to material that was deliberately removed. Account identifiers, emails and
account inventories are replaced with placeholders (`<account-id>`, `<profile-A>`, `<switcher>` …).
